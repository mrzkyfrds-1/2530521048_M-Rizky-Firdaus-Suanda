PRAKTIKUM PBO PERTEMUAN 4
Constructor, Destructor, dan Overloading pada PHP

File:
1. constructor.php - constructor dan nilai default
2. destructor.php - destructor dan referensi object
3. overloading_property.php - __get, __set, __isset, __unset
4. overloading_method.php - __call

Cara menjalankan:
1. Simpan folder ini di C:\xampp\htdocs\pbo_php\pertemuan_04
2. Jalankan Apache dari XAMPP.
3. Buka masing-masing file melalui browser:
   http://localhost/tugas-pbo/praktikum_04/constructor.php
   http://localhost/tugas-pbo/praktikum_04/destructor.php
   http://localhost/tugas-pbo/praktikum_04/overloading_property.php
   http://localhost/tugas-pbo/praktikum_04/overloading_method.php

Gunakan PHP 8.x dan ambil screenshot hasil setiap file untuk laporan.
